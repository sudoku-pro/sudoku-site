# 安装

Sudoku 已在 App Store 上架，是一款通用 App，一次购买即可在 iPhone、iPad 和 Mac 上使用。

## 下载

- **App Store**：[下载 Sudoku](https://apps.apple.com/app/id6793606018) —— 支持 iPhone、iPad 与 Mac 的通用 App

### App Store（推荐）

App Store 版本可自动更新，并与你的所有 Apple 设备无缝集成。

- **App Store ID**：6793606018
- **链接**：https://apps.apple.com/app/id6793606018
- **平台**：iPhone、iPad、Mac（通用 App）
- **价格**：请查看 App Store 页面了解当前价格

## 安装步骤

### iPhone / iPad

1. 在设备上打开 **App Store**
2. 搜索“Sudoku”，或使用上面的直接链接
3. 点按 **获取** 或 **购买** 进行下载
4. 应用会自动安装
5. 从主屏幕启动 Sudoku

### Mac

1. 在 Mac 上打开 **App Store**
2. 搜索“Sudoku”，或使用上面的直接链接
3. 点按 **获取** 或 **购买** 完成购买
4. 应用会自动下载并安装
5. 从“应用程序”文件夹或启动台启动 Sudoku

## 首次启动

首次启动 Sudoku 时，应用会请求访问 iCloud（用于同步）和 Game Center（用于排行榜和成就）的权限。这两项都是可选的——不授予权限也能完整离线游玩。

## 更新

更新由 App Store 自动处理。如需手动检查更新，请打开 App Store，进入 **账户 → 更新** 页面。

## 卸载

### iPhone / iPad

1. 长按 Sudoku 应用图标
2. 点按 **移除 App** → **删除 App**

### Mac

1. 退出 Sudoku
2. 将 `Sudoku.app` 从 `Applications` 拖到废纸篓
3. （可选）清除应用数据：

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

## 系统要求

- **iPhone/iPad**：iOS/iPadOS 16.0 或更高版本
- **Mac**：macOS 15.0（Sequoia）或更高版本
- **CPU**：Apple Silicon（M 系列）
- **内存**：最低 2GB
- **存储空间**：约 50 MB
- **网络**：游玩不需要网络（iCloud 和 Game Center 为可选）

## 故障排查

如果安装过程中遇到问题：

- **macOS 阻止了应用运行**：打开 **系统设置 → 隐私与安全性**，然后为 Sudoku 点按 **仍要打开**
- **应用没有出现**：重启 App Store 或你的设备后重试

如需更多帮助，请参阅[故障排查指南](./troubleshooting)，或在项目仓库中提交 issue。
