# 隐私选择

Sudoku 是一款以离线为先、数据处理极简的应用。本页说明您有哪些隐私选项，以及如何控制自己的数据。

## 您的数据默认留在您的设备上

- 所有游戏数据——设置、游戏状态、铅笔笔记和统计数据——默认存储在您的设备本地。
- 核心玩法无需任何网络访问。
- 没有广告，没有数据分析，也没有追踪。

## 可选的云功能

### iCloud 同步

如果您选择启用 iCloud 同步：

- 数据只会同步到**您个人的 iCloud 账户**——不会同步到我们控制的任何服务器。
- 传输和存储过程中的加密由 Apple 的 CloudKit 负责。
- 您可以随时关闭此功能：设置 → [你的名字] → iCloud → 使用 iCloud 的 App → 关闭 Sudoku 的开关。

### Game Center

如果您选择使用 Game Center：

- 排行榜成绩可能会以您的 Game Center 显示名称公开显示。
- 成就进度会由 Game Center 记录。
- 您可以在设置中退出 Game Center 登录来关闭此功能。

## 唯一的非云端网络功能：“更多 App”

唯一的其他网络访问，是设置中可选的 **“更多 App”** 板块，它会获取同系列应用的列表。此功能：

- 不发送任何个人数据——仅获取一份应用名称与链接列表。
- 完全可以忽略，对游戏体验没有任何影响。
- 不会追踪您，也不会存储任何标识符。

## 清除您的数据

如需从设备上移除应用的全部数据：

- **iPhone/iPad**：删除并重新安装应用
- **Mac**：退出 Sudoku，然后删除容器：

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

如需一并清除 iCloud 中同步的数据：
1. 进入 **设置 → [你的名字] → iCloud → 管理账户储存空间**
2. 在应用列表中找到 Sudoku
3. 点按 **删除数据**

此操作将从 iCloud 中永久删除所有设置、统计数据、游戏存档和每日挑战进度。

## 无追踪，无广告

Sudoku 不含任何广告、数据分析、追踪像素，也不含任何第三方数据共享集成。游玩本应用不需要网络访问。

## 隐私请求概要

| 请求 | 是否必需？ | 作用 |
|---------|-----------|-------------|
| 本地存储 | 是（自动） | 将游戏数据存储在设备上 |
| iCloud 同步 | 可选 | 通过 CloudKit 在您的设备间同步数据 |
| Game Center | 可选 | 排行榜与成就 |
| 网络（“更多 App”） | 可选 | 获取同系列应用列表 |

由于我们不收集任何个人数据，也不会将其传输到我们控制的服务器，因此不存在可供访问、删除或迁移的中央数据库。所有数据要么存储在本地，要么由 Apple 的服务（iCloud/Game Center）管理。
