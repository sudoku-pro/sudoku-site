# Installation

Sudoku ist als universelle App im App Store erhältlich und unterstützt iPhone, iPad und Mac mit einem einzigen Kauf.

## Download

- **App Store**: [Sudoku herunterladen](https://apps.apple.com/app/id6793606018) — universelle App für iPhone, iPad & Mac

### App Store (empfohlen)

Die App-Store-Version bietet automatische Updates und eine nahtlose Integration in alle Ihre Apple-Geräte.

- **App Store ID**: 6793606018
- **Link**: https://apps.apple.com/app/id6793606018
- **Plattformen**: iPhone, iPad, Mac (universelle App)
- **Preis**: Die aktuellen Preise finden Sie im App-Store-Eintrag

## Installationsschritte

### iPhone / iPad

1. Öffnen Sie den **App Store** auf Ihrem Gerät
2. Suchen Sie nach „Sudoku“ oder verwenden Sie den direkten Link oben
3. Tippen Sie auf **Laden** oder **Kaufen**, um die App herunterzuladen
4. Die App wird automatisch installiert
5. Starten Sie Sudoku über den Home-Bildschirm

### Mac

1. Öffnen Sie den **App Store** auf Ihrem Mac
2. Suchen Sie nach „Sudoku“ oder verwenden Sie den direkten Link oben
3. Klicken Sie auf **Laden** oder **Kaufen**, um die App zu erwerben
4. Die App wird automatisch heruntergeladen und installiert
5. Starten Sie Sudoku aus dem Ordner „Programme“ oder über Launchpad

## Erster Start

Beim ersten Start von Sudoku fragt die App nach der Berechtigung für iCloud (Synchronisierung) und Game Center (Ranglisten und Erfolge). Beides ist optional – das Spiel funktioniert auch ohne vollständig offline.

## Updates

Updates werden automatisch über den App Store bereitgestellt. Um manuell nach Updates zu suchen, öffnen Sie den App Store und wechseln Sie zum Bereich **Account → Updates**.

## Deinstallation

### iPhone / iPad

1. Halten Sie das Sudoku-App-Symbol gedrückt
2. Tippen Sie auf **App entfernen** → **App löschen**

### Mac

1. Beenden Sie Sudoku
2. Ziehen Sie `Sudoku.app` aus `Applications` in den Papierkorb
3. (Optional) App-Daten entfernen:

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

## Systemanforderungen

- **iPhone/iPad**: iOS/iPadOS 16.0 oder neuer
- **Mac**: macOS 15.0 (Sequoia) oder neuer
- **CPU**: Apple Silicon (M-Serie)
- **Arbeitsspeicher**: mindestens 2 GB
- **Speicherplatz**: ca. 50 MB
- **Netzwerk**: für das Spielen nicht erforderlich (iCloud/Game Center optional)

## Problembehandlung

Falls bei der Installation Probleme auftreten:

- **macOS blockiert die App**: Öffnen Sie **Systemeinstellungen → Datenschutz & Sicherheit** und klicken Sie bei Sudoku auf **Dennoch öffnen**
- **App wird nicht angezeigt**: Starten Sie den App Store oder Ihr Gerät neu und versuchen Sie es erneut

Weitere Hilfe finden Sie in der [Anleitung zur Problembehandlung](./troubleshooting) oder Sie eröffnen ein Issue im Projekt-Repository.
