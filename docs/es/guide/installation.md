# Instalación

Sudoku está disponible como app universal en la App Store, compatible con iPhone, iPad y Mac con una sola compra.

## Descarga

- **App Store**: [Descargar Sudoku](https://apps.apple.com/app/id6793606018) — app universal para iPhone, iPad y Mac

### App Store (recomendado)

La versión de la App Store ofrece actualizaciones automáticas y una integración perfecta en todos tus dispositivos Apple.

- **ID de App Store**: 6793606018
- **Enlace**: https://apps.apple.com/app/id6793606018
- **Plataformas**: iPhone, iPad, Mac (app universal)
- **Precio**: consulta la ficha de la App Store para conocer el precio actual

## Pasos de instalación

### iPhone / iPad

1. Abre la **App Store** en tu dispositivo
2. Busca «Sudoku» o usa el enlace directo de arriba
3. Toca **Obtener** o **Comprar** para descargar
4. La app se instalará automáticamente
5. Abre Sudoku desde la pantalla de inicio

### Mac

1. Abre la **App Store** en tu Mac
2. Busca «Sudoku» o usa el enlace directo de arriba
3. Haz clic en **Obtener** o **Comprar** para adquirirla
4. La app se descargará e instalará automáticamente
5. Abre Sudoku desde la carpeta Aplicaciones o desde Launchpad

## Primer inicio

La primera vez que abras Sudoku, se te pedirá permiso para acceder a iCloud (para la sincronización) y a Game Center (para clasificaciones y logros). Son permisos opcionales: el juego funciona perfectamente sin conexión y sin ellos.

## Actualizaciones

La App Store se encarga de las actualizaciones automáticamente. Para buscar actualizaciones manualmente, abre la App Store y ve a la sección **Cuenta → Actualizaciones**.

## Desinstalación

### iPhone / iPad

1. Mantén pulsado el icono de la app Sudoku
2. Toca **Eliminar app** → **Borrar app**

### Mac

1. Cierra Sudoku
2. Arrastra `Sudoku.app` desde `Applications` a la papelera
3. (Opcional) Elimina los datos de la app:

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

## Requisitos del sistema

- **iPhone/iPad**: iOS/iPadOS 16.0 o posterior
- **Mac**: macOS 15.0 (Sequoia) o posterior
- **CPU**: Apple Silicon (serie M)
- **Memoria**: 2 GB como mínimo
- **Almacenamiento**: ~50 MB
- **Red**: no es necesaria para jugar (iCloud y Game Center son opcionales)

## Solución de problemas

Si tienes problemas durante la instalación:

- **macOS bloquea la app**: abre **Ajustes del Sistema → Privacidad y seguridad** y haz clic en **Abrir igualmente** para Sudoku
- **La app no aparece**: reinicia la app App Store o tu dispositivo e inténtalo de nuevo

Para más ayuda, consulta la [guía de solución de problemas](./troubleshooting) o abre un issue en el repositorio del proyecto.
