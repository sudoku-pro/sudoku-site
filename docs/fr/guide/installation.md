# Installation

Sudoku est disponible en tant qu'application universelle sur l'App Store : elle prend en charge iPhone, iPad et Mac avec un seul achat.

## Téléchargement

- **App Store** : [Télécharger Sudoku](https://apps.apple.com/app/id6793606018) — application universelle pour iPhone, iPad et Mac

### App Store (recommandé)

La version de l'App Store bénéficie de mises à jour automatiques et d'une intégration transparente sur tous vos appareils Apple.

- **Identifiant App Store** : 6793606018
- **Lien** : https://apps.apple.com/app/id6793606018
- **Plateformes** : iPhone, iPad, Mac (application universelle)
- **Prix** : consultez la fiche App Store pour connaître le tarif actuel

## Étapes d'installation

### iPhone / iPad

1. Ouvrez l'**App Store** sur votre appareil
2. Recherchez « Sudoku » ou utilisez le lien direct ci-dessus
3. Touchez **Obtenir** ou **Acheter** pour télécharger
4. L'application s'installe automatiquement
5. Lancez Sudoku depuis votre écran d'accueil

### Mac

1. Ouvrez l'**App Store** sur votre Mac
2. Recherchez « Sudoku » ou utilisez le lien direct ci-dessus
3. Cliquez sur **Obtenir** ou **Acheter** pour effectuer l'achat
4. L'application se télécharge et s'installe automatiquement
5. Lancez Sudoku depuis le dossier Applications ou Launchpad

## Premier lancement

Lors du premier lancement de Sudoku, l'application vous demande l'autorisation d'accéder à iCloud (pour la synchronisation) et à Game Center (pour les classements et les succès). Ces autorisations sont facultatives : le jeu fonctionne parfaitement hors ligne sans elles.

## Mises à jour

Les mises à jour sont gérées automatiquement par l'App Store. Pour rechercher des mises à jour manuellement, ouvrez l'App Store et rendez-vous dans la section **Compte → Mises à jour**.

## Désinstallation

### iPhone / iPad

1. Maintenez le doigt appuyé sur l'icône de l'application Sudoku
2. Touchez **Supprimer l'app** → **Supprimer l'app**

### Mac

1. Quittez Sudoku
2. Faites glisser `Sudoku.app` depuis `Applications` vers la corbeille
3. (Facultatif) Supprimez les données de l'application :

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

## Configuration requise

- **iPhone/iPad** : iOS/iPadOS 16.0 ou version ultérieure
- **Mac** : macOS 15.0 (Sequoia) ou version ultérieure
- **Processeur** : Apple Silicon (série M)
- **Mémoire** : 2 Go minimum
- **Stockage** : ~50 Mo
- **Réseau** : non requis pour jouer (iCloud et Game Center sont facultatifs)

## Dépannage

Si vous rencontrez des difficultés lors de l'installation :

- **macOS bloque l'application** : ouvrez **Réglages Système → Confidentialité et sécurité** et cliquez sur **Ouvrir quand même** pour Sudoku
- **L'application n'apparaît pas** : redémarrez l'App Store ou votre appareil, puis réessayez

Pour obtenir de l'aide, consultez le [guide de dépannage](./troubleshooting) ou ouvrez une issue sur le dépôt du projet.
