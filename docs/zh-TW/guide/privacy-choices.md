# 隱私權選項

Sudoku 是一款以離線優先為設計原則的 App，資料處理方式極為單純。本頁說明你有哪些隱私選項，以及如何掌控自己的資料。

## 你的資料預設留在裝置上

- 所有遊戲資料——設定、遊戲狀態、鉛筆筆記與統計資料——預設都儲存在你的裝置本機。
- 核心玩法完全不需要網路存取。
- 沒有廣告、沒有分析工具，也沒有追蹤。

## 選用的雲端功能

### iCloud 同步

如果你選擇啟用 iCloud 同步：

- 資料只會同步到**你的個人 iCloud 帳號**，不會傳到我們控制的任何伺服器。
- 傳輸過程與存放時的加密皆由 Apple 的 CloudKit 處理。
- 你隨時可以關閉此功能：設定 →［你的名字］→ iCloud →「使用 iCloud 的 App」→ 將 Sudoku 關閉。

### Game Center

如果你選擇使用 Game Center：

- 排行榜分數可能會以你的 Game Center 顯示名稱公開顯示。
- 成就進度由 Game Center 記錄。
- 你可以在「設定」中登出 Game Center 來停用此功能。

## 唯一的非雲端網路功能：「更多 App」

唯一的其他網路存取，是「設定」中選用的**「更多 App」**區塊，會取得一系列相關 App 的清單。此功能：

- 不傳送任何個人資料——只會取得 App 名稱與連結的清單。
- 可以完全忽略，對遊戲體驗沒有任何影響。
- 不會追蹤你，也不會儲存任何識別碼。

## 清除你的資料

若要從裝置移除所有 App 資料：

- **iPhone/iPad**：刪除並重新安裝 App
- **Mac**：結束 Sudoku，然後移除容器：

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

若要一併清除 iCloud 中同步的資料：

1. 前往 **設定 →［你的名字］→ iCloud → 管理帳號儲存空間**
2. 在 App 清單中找到 Sudoku
3. 點一下 **刪除資料**

這會從 iCloud 永久刪除所有設定、統計資料、遊戲存檔與每日挑戰進度。

## 不追蹤、沒有廣告

Sudoku 不含任何廣告、分析工具、追蹤像素或第三方資料分享整合。本 App 遊玩時不需要網路存取。

## 隱私權請求一覽

| 請求 | 是否必要 | 作用 |
|---------|-----------|-------------|
| 本機儲存 | 是（自動） | 將遊戲資料儲存在裝置上 |
| iCloud 同步 | 選用 | 透過 CloudKit 在裝置間同步資料 |
| Game Center | 選用 | 排行榜與成就 |
| 網路（「更多 App」） | 選用 | 取得相關 App 清單 |

由於我們未蒐集任何個人資料，也未將其傳送到我們控制的伺服器，因此並沒有可供存取、刪除或匯出的中央資料庫。所有資料不是在本機，就是由 Apple 的服務（iCloud／Game Center）管理。
