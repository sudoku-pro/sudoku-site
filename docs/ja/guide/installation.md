# インストール

Sudoku は App Store でユニバーサルアプリとして提供されており、1 回の購入で iPhone、iPad、Mac に対応します。

## ダウンロード

- **App Store**：[Sudoku をダウンロード](https://apps.apple.com/app/id6793606018) — iPhone、iPad、Mac 対応のユニバーサルアプリ

### App Store（推奨）

App Store 版は自動アップデートに対応し、お持ちのすべての Apple デバイスとシームレスに連携します。

- **App Store ID**：6793606018
- **リンク**：https://apps.apple.com/app/id6793606018
- **対応プラットフォーム**：iPhone、iPad、Mac（ユニバーサルアプリ）
- **価格**：現在の価格は App Store の掲載情報をご確認ください

## インストール手順

### iPhone / iPad

1. デバイスで **App Store** を開きます
2. 「Sudoku」を検索するか、上記の直接リンクを使用します
3. **入手** または **購入** をタップしてダウンロードします
4. アプリは自動的にインストールされます
5. ホーム画面から Sudoku を起動します

### Mac

1. Mac で **App Store** を開きます
2. 「Sudoku」を検索するか、上記の直接リンクを使用します
3. **入手** または **購入** をクリックして購入します
4. アプリは自動的にダウンロードされインストールされます
5. アプリケーションフォルダまたは Launchpad から Sudoku を起動します

## 初回起動

Sudoku を初めて起動すると、iCloud（同期用）と Game Center（リーダーボードと実績用）へのアクセス許可が求められます。これらは任意です — 許可しなくてもゲームは完全にオフラインで動作します。

## アップデート

アップデートは App Store によって自動的に処理されます。手動で確認するには、App Store を開き、**アカウント → アップデート** のセクションに移動してください。

## アンインストール

### iPhone / iPad

1. Sudoku のアプリアイコンを長押しします
2. **App を削除** → **App を削除** をタップします

### Mac

1. Sudoku を終了します
2. `Applications` から `Sudoku.app` をゴミ箱にドラッグします
3. （任意）アプリデータを削除します：

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

## システム要件

- **iPhone/iPad**：iOS/iPadOS 16.0 以降
- **Mac**：macOS 15.0（Sequoia）以降
- **CPU**：Apple Silicon（M シリーズ）
- **メモリ**：最低 2GB
- **ストレージ**：約 50 MB
- **ネットワーク**：ゲームプレイには不要（iCloud／Game Center は任意）

## トラブルシューティング

インストール中に問題が発生した場合：

- **macOS がアプリをブロックする**：**システム設定 → プライバシーとセキュリティ** を開き、Sudoku の **このまま開く** をクリックします
- **アプリが表示されない**：App Store アプリまたはデバイスを再起動して、もう一度お試しください

さらに詳しい情報は[トラブルシューティングガイド](./troubleshooting)をご覧いただくか、プロジェクトリポジトリで issue を作成してください。
