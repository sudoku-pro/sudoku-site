# プライバシーポリシー

Sudoku は、任意のクラウド機能を備えたオフラインファーストのアプリケーションです。本ページでは、本アプリが収集するデータ（収集する場合）とその利用方法について説明します。

## オフラインの中核機能 — ゲームプレイにおけるデータ収集はありません

- パズルゲームの中核部分は完全にオフラインでプレイできます。プレイにネットワークアクセスは不要です。
- 設定、ゲームの状態、鉛筆メモ、統計などのすべてのゲームデータは、お使いのデバイス内にローカル保存されます。
- 広告、分析、サードパーティのトラッキング SDK は一切ありません。

## 任意のクラウド機能

### iCloud 同期（CloudKit）

iCloud にサインインし、同期を有効にした場合：

- ゲームのセーブデータ、統計、設定、デイリーチャレンジの進捗は、Apple の CloudKit サービスを通じて**お客様個人の iCloud アカウント**に同期されます。
- データは Apple のインフラストラクチャにより、転送時および保存時のいずれにおいても暗号化されます。
- 同期されたデータにアクセスできるのは、お客様の Apple ID を使用するお客様ご自身のみです。
- この機能は完全に任意です — 利用しなくてもアプリは問題なく動作します。

### Game Center

Game Center にサインインした場合：

- リーダーボードのスコア（難易度ごとのベストクリアタイム）が公開リーダーボードで共有される場合があります。
- 実績の進捗は Apple の Game Center サービスによって記録されます。
- Game Center の表示名は、リーダーボード上で他のプレイヤーから見ることができます。
- この機能は完全に任意です。

## その他にネットワークへアクセスする唯一の機能：「More Apps」

クラウド以外でネットワークにアクセスする唯一の機能は、設定内の任意の **「More Apps」** セクションであり、当社のサーバーから姉妹アプリの一覧を取得します。この機能は：

- 設定 → More Apps に移動したときにのみ動作します。
- アプリ名とリンクの軽量な一覧を取得するだけで、個人データの送信や保存は行いません。
- まったく利用しなくてもよく、ゲームプレイには一切影響しません。

## 収集しない情報

- 個人情報、ファイル、画像、閲覧履歴は収集しません。
- ゲームデータを外部サーバーに送信することはありません（上記の iCloud／Game Center に関する記載を除きます）。
- サードパーティの分析 SDK や広告 SDK は組み込んでいません。
- クラッシュレポートやテレメトリのサービスは使用していません。

## 権限

Sudoku が必要とする権限は最小限です：

- **iCloud**（任意）：CloudKit を通じてデバイス間でゲームデータを同期するため。
- **Game Center**（任意）：リーダーボードと実績のため。
- **ネットワーク**（任意）：iCloud 同期、Game Center、「More Apps」のため。

位置情報、連絡先、カメラ、マイク、その他プライバシーに関わる権限は要求しません。

## データの保持

- ローカルデータは、アプリをアンインストールするかリセットするまで、お使いのデバイス内に残ります。
- iCloud で同期されたデータは、Apple の iCloud データ保持ポリシーに従います。
- Game Center のデータは、Apple の Game Center ポリシーに従います。

## プライバシーに関するご請求

Sudoku はすべてのデータをローカル（および任意でお客様個人の iCloud）に保存するため、当社が管理またはアクセスするサーバー側のデータは存在しません。アプリのデータをすべて消去するには：

- お使いのデバイスから**アプリをアンインストール**します。
- **iCloud のデータをリセット**：設定 → [あなたの名前] → iCloud → アカウントのストレージを管理 → Sudoku → データを削除。
- **Mac のローカルリセット**：コンテナの削除手順についてはトラブルシューティングガイドをご覧ください。

## お子様のプライバシー

Sudoku は、お子様を含む誰からも個人情報を積極的に収集することはありません。本アプリはアカウント、チャット機能、ソーシャルネットワーキングを必要としません。
