# プライバシーの選択肢

Sudoku は、データの取り扱いを最小限に抑えたオフラインファーストのアプリです。本ページでは、プライバシーに関する選択肢と、データを管理する方法について説明します。

## データは（既定で）お使いのデバイス内に留まります

- 設定、ゲームの状態、鉛筆メモ、統計などのすべてのゲームデータは、既定でお使いのデバイス内にローカル保存されます。
- 中核となるゲームプレイにネットワークアクセスは一切不要です。
- 広告、分析、トラッキングはありません。

## 任意のクラウド機能

### iCloud 同期

iCloud 同期を有効にした場合：

- データは**お客様個人の iCloud アカウント**にのみ同期され、当社が管理するサーバーには同期されません。
- 転送時および保存時の暗号化は Apple の CloudKit が処理します。
- いつでも無効にできます：設定 → [あなたの名前] → iCloud → iCloud を使用する App → Sudoku をオフにする。

### Game Center

Game Center を利用する場合：

- リーダーボードのスコアが、Game Center の表示名で公開される場合があります。
- 実績の進捗は Game Center によって記録されます。
- 設定で Game Center からサインアウトすると無効にできます。

## クラウド以外でネットワークを使う唯一の機能：「More Apps」

他にネットワークへアクセスするのは、設定内の任意の **「More Apps」** セクションのみで、姉妹アプリの一覧を取得します。この機能は：

- 個人データを一切送信せず、アプリ名とリンクの一覧を取得するだけです。
- 完全に無視してもゲームプレイに影響はありません。
- お客様をトラッキングしたり、識別子を保存したりすることはありません。

## データの消去

デバイスからアプリのデータをすべて削除するには：

- **iPhone/iPad**：アプリを削除して再インストールします
- **Mac**：Sudoku を終了してから、コンテナを削除します：

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

iCloud で同期されたデータもあわせて消去するには：
1. **設定 → [あなたの名前] → iCloud → アカウントのストレージを管理** に移動します
2. アプリ一覧から Sudoku を探します
3. **データを削除** をタップします

これにより、設定、統計、ゲームのセーブデータ、デイリーチャレンジの進捗がすべて iCloud から完全に削除されます。

## トラッキングなし、広告なし

Sudoku には、広告、分析、トラッキングピクセル、サードパーティとのデータ共有連携が一切含まれていません。本アプリはゲームプレイにネットワークアクセスを必要としません。

## プライバシーに関するご請求の概要

| ご請求 | 必須か | 内容 |
|---------|-----------|-------------|
| ローカル保存 | 必須（自動） | ゲームデータをデバイス内に保存します |
| iCloud 同期 | 任意 | CloudKit を通じてデバイス間でデータを同期します |
| Game Center | 任意 | リーダーボードと実績 |
| ネットワーク（「More Apps」） | 任意 | 姉妹アプリの一覧を取得します |

個人データを収集したり、当社が管理するサーバーへ送信したりすることはないため、アクセス・削除・移行の対象となる中央データベースは存在しません。すべてのデータはローカルに保存されるか、Apple のサービス（iCloud／Game Center）によって管理されます。
