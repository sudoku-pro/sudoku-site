# トラブルシューティング

このページでは、よくある問題とその解決方法をまとめています。

## アプリが起動しない、起動直後にクラッシュする

症状：Sudoku が開かない、すぐにクラッシュする、予期しないエラーが表示される。

お試しいただきたい手順：

1. デバイスが最低要件（iOS/iPadOS 16 以降、macOS 15 以降）を満たしていることを確認します。
2. アプリを強制終了してから再起動します。
3. デバイスを再起動します。
4. App Store からアプリを再インストールします。
5. 問題が解決しない場合は、詳細を添えてプロジェクトリポジトリで issue を作成してください。

## 動作が重い

ゲームの動作が遅い、カクつく場合：

1. 負荷の高い他のアプリを終了します。
2. Mac では、アクティビティモニタで CPU 使用率が高くないか確認します。
3. 古いデバイスでは、より簡単な難易度（やさしいまたはふつう）を試してください。

## iCloud の同期が機能しない

進行状況がデバイス間で同期されない場合：

1. すべてのデバイスで同じ Apple ID にサインインしていることを確認します。
2. システム設定（Mac）または設定（iOS/iPadOS）で iCloud Drive が有効になっていることを確認します。
3. インターネット接続が有効であることを確認します。
4. 設定 → [あなたの名前] → iCloud → iCloud を使用する App で、Sudoku の iCloud を一度オフにしてから再度オンにします。
5. すべてのデバイスを再起動して、もう一度お試しください。

## Game Center に接続できない

Game Center の実績やリーダーボードが更新されない場合：

1. Game Center にサインインしていることを確認します（iOS では設定 → Game Center、Mac ではシステム設定）。
2. インターネット接続を確認します。
3. Game Center からサインアウトし、再度サインインします。

## ログを確認する

クラッシュの原因を調べるには、アプリケーションログが役立ちます。Mac のサンドボックス（App Store）版では、次を確認してください：

```
~/Library/Containers/com.w3cub.sudoku/Data/Library/Logs/sudoku/sudoku.log
```

iOS/iPadOS では、デバイスを Mac に接続し、Console.app で「Sudoku」で絞り込んでログを表示します。

## アプリをリセットする

設定を初期化し、ローカルデータを消去する方法（Mac）：

1. Sudoku を終了します
2. コンテナを削除します（注意 — 設定、統計、ゲームのセーブデータがすべて削除されます）：

```bash
rm -rf ~/Library/Containers/com.w3cub.sudoku
```

3. Sudoku を再度開き、設定し直します。

iPhone/iPad では、アプリを削除して再インストールするとすべてのデータがリセットされます。

**注意**：iCloud 同期を使用している場合、1 台のデバイスでリセットしても、再起動後に iCloud からデータが再ダウンロードされることがあります。すべてのデバイスで完全にリセットするには、各デバイスでリセットが必要になる場合があります。

## 問題を報告する

issue を作成する際は、次の情報を含めてください：

- デバイスの種類（iPhone、iPad、Mac）
- OS のバージョン（設定 → 一般 → 情報）
- Sudoku のバージョン（設定 → 概要）
- 問題の再現手順
- 可能であればログやスクリーンショット

これらの情報があると、メンテナーが問題を特定し、より早く修正できます。
