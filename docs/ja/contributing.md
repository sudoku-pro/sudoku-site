# コントリビュート

Sudoku のドキュメントをより良くするための貢献を歓迎します！誤字の修正、新しいガイドの追加、既存コンテンツの改善など、どんな形のご協力もありがたく受け取ります。

## 貢献の方法

### ドキュメントの改善
- 誤字や文法の誤りを修正する
- 分かりにくい説明を明確にする
- 不足している情報を追加する
- 古くなった内容を更新する
- 書式や読みやすさを改善する

### 新しいコンテンツ
- よくある問題についてのガイドを作成する
- チュートリアルやサンプルを追加する
- ドキュメントを他の言語に翻訳する
- FAQ の項目を書く

### 技術的な貢献
- ビルドプロセスを改善する
- ドキュメントサイトに新しい機能を追加する
- デプロイのワークフローにあるバグを修正する

## はじめに

### 前提条件
- Node.js 18 以降
- pnpm パッケージマネージャー
- Git

### 開発環境のセットアップ

1. GitHub で**リポジトリをフォーク**します
2. **フォークをクローン**します：
   ```bash
   git clone https://github.com/YOUR_USERNAME/sudoku-site.git
   cd sudoku-site
   ```
3. **依存関係をインストール**します：
   ```bash
   pnpm install
   ```
4. **開発サーバーを起動**します：
   ```bash
   pnpm docs:dev
   ```
5. ブラウザで `http://localhost:5173` を開きます

### 変更を加える

1. 変更用の新しいブランチを作成します：
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. `docs/` 内のドキュメントファイルを編集します
3. サイトをビルドして変更をテストします：
   ```bash
   pnpm docs:build
   ```
4. 変更をコミットします：
   ```bash
   git add .
   git commit -m "Description of your changes"
   ```

### 変更を送信する

1. **ブランチをフォークにプッシュ**します：
   ```bash
   git push origin feature/your-feature-name
   ```
2. GitHub で **Pull Request を作成**します
3. **レビューを待ち**、フィードバックに対応します

## ガイドライン

### 文章スタイル
- 明確で簡潔な言葉を使う
- できるだけ能動態で書く
- 誰にでも開かれた歓迎的な表現にする
- 一貫した書式を使う
- 必要に応じてコード例を入れる

### ファイル構成
- ドキュメントページは `docs/` に置く
- ガイドは `docs/guide/` に置く
- ファイル名は小文字とハイフンを使う：`my-new-guide.md`
- frontmatter は必須ではありませんが、メタデータに利用できます

### リンク
- 内部ドキュメントへのリンクは相対リンクを使う
- 必要に応じて外部リソースへリンクする
- すべてのリンクが機能することを確認する

### 画像とアセット
- 画像は `docs/public/` またはそのサブディレクトリに置く
- 内容が分かるファイル名を使う
- Web 向けに画像を最適化する（500KB 未満が望ましい）
